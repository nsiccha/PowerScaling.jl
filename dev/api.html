PowerScaling.cjs_dist Function
julia
cjs_dist(x, y; x_weights=nothing, y_weights=nothing)

Cumulative Jensen-Shannon distance between two samples, following R priorsense cjs_dist (base-2 logs, upper-bound normalisation, square-root metric, unsigned max over x/-x). Weights default to uniform. x and y are usually the SAME posterior draws with uniform versus power-scaling weights, in which case the weighted-ECDF fast path applies. Unequal supports use the priorsense equally spaced grid with max(length(x), length(y)) bins; this is a finite-sample approximation to the continuous distance.

Inputs must be finite with at least two draws each; weights must be finite, nonnegative, and not all zero. A point mass compared against itself is distance 0.0 (R priorsense returns NaN there, an arithmetic artifact).

PowerScaling.powerscale_weights Function
julia
powerscale_weights(log_component; alpha, reff=1.0)

Pareto-smoothed weights for raising a prior or likelihood component to alpha. The importance log ratios are (alpha - 1) * log_component. Supply one finite joint log-density per posterior draw, in draw order. Additive constants cancel. alpha must be finite and nonnegative; reff is the relative efficiency of the inverse importance ratios, as in PSIS.psis (1 for independent draws).

Returns a named tuple with normalized weights, normalized log_weights, pareto_k, tail_length, ess, and alpha. ESS is reff / sum(abs2, weights); it is descriptive only when the Pareto fit is reliable. A nonfinite Pareto-k or a value above 0.7 signals unreliable reweighting. PSIS warnings are retained.

At alpha == 1, returns uniform weights, pareto_k = -Inf, tail_length = 0, and ess = reff * length(log_component). Otherwise at least 21 draws and a nonconstant component are required, and the PSIS tail must have at least five draws. Constant components cannot diagnose sensitivity by power-scaling. Inputs are never modified.

PowerScaling.powerscale_sensitivity Function
julia
powerscale_sensitivity(draws, log_prior, log_lik;
    names=Symbol.("x" .* string.(1:size(draws, 2))), variables=nothing,
    lower_alpha=0.99, upper_alpha=1.01, threshold=0.05, reff=1.0)
powerscale_sensitivity(draws, log_prior, log_lik, names; kwargs...)

Prior and likelihood sensitivity following Kallioinen et al. (2024). draws is a matrix with one draw per row and one variable per column; log_prior and log_lik contain the joint log densities for those same draws. names labels the columns; variables selects and orders names (default: all). The optional fourth positional argument is equivalent to the names keyword.

For each component, PSIS reweights draws at lower_alpha and upper_alpha. The sensitivity is the mean of the one-sided CJS distance gradients: (D_lower / -log2(lower_alpha) + D_upper / log2(upper_alpha)) / 2. Require 0 < lower_alpha < 1 < upper_alpha and a finite nonnegative threshold. reff is passed to all four PSIS fits; use 1 for independent draws. When the four inverse-ratio efficiencies differ, supply their conservative minimum. The lower-level powerscale_weights accepts a separate value per call.

Only the supplied density components are scaled. For hierarchical models, choose the prior levels to perturb explicitly, and evaluate those components in a consistent parameterization. Model assembly, density evaluation, refits, and moment matching belong to the caller. Check reliable before interpreting the returned PowerscaleSensitivity.

PowerScaling.PowerscaleSensitivity Type
julia
PowerscaleSensitivity

Per-variable power-scaling diagnostics, returned by powerscale_sensitivity. variables, prior, likelihood, and diagnosis are aligned vectors. Diagnoses are :prior_data_conflict (both sensitivities ≥ threshold), :strong_prior_weak_likelihood (prior > threshold, likelihood < threshold), or :none. These are potential concerns, not hypothesis tests.

pareto_k contains prior_lower, prior_upper, likelihood_lower, and likelihood_upper. reliable.prior and reliable.likelihood indicate whether both Pareto-k values for that component are finite and ≤ 0.7. These flags assess importance sampling, not convergence of the input posterior draws. Unreliable sensitivities remain visible and must not be interpreted as evidence of sensitivity or its absence.
